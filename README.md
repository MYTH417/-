# 记账本 (Vue 3 个人记账 App)

这是一个基于 Vue 3 + Vite 开发的个人记账应用。

## 🌐 在线预览
👉 **点击体验网页版**：https://wondrous-melba-7ebf4a.netlify.app/

## ✨ 功能特点
- 支持添加收入/支出，包含金额、分类、日期、备注
- 首页实时统计总收入、总支出和当前余额
- ECharts 图表展示：支出分类饼图、近 7 日收支柱状图
- 账单列表查看，并支持居中弹窗二次确认删除
- localStorage 本地存储，刷新页面数据不丢失
- 响应式设计，完美适配手机屏幕

## 🚀 本地运行
1. `npm install`
2. `npm run dev`
